# Black Dragon — Black Kitty Fix

A hobby project based on Black Dragon, with an AMD fix for texture and shadow
flickering on affected meshes. It keeps Black Dragon's posing, photography,
motion blur and other viewer features.

**Black Kitty Fix 1.0.0**, based on **Black Dragon 26.2.0.57700 —
5.6.3 “Favorite Dragon.”** The fix version is separate from the official base.

Updates may be made to keep this build up to date with Black Dragon and maintain
the AMD fix for as long as it is not included in official Black Dragon.

## Download and updates

Download the Windows x64 installer from the
[latest release](https://github.com/NekoMisa/Black-Dragon---Black-Kitty-Fix/releases/latest).
Each release includes matching source and SHA-256 checksums.

Version 1.0.0 adds built-in update checks. Use **Check for Updates on the login screen or in About**;
startup checks are optional. Downloads and installation require your approval.
Existing users must install this version manually once to get the updater.
The unsigned installer requests administrator permission. Updates and uninstall
preserve your separate Black Kitty Fix settings and cache.

## My viewer projects

- [Black Dragon — Black Kitty Fix](https://github.com/NekoMisa/Black-Dragon---Black-Kitty-Fix)
  is a Black Dragon build focused on the AMD texture and shadow flicker fix,
  preserving Black Dragon's features and adding built-in update checks.
- [Stellarys Viewer](https://github.com/NekoMisa/stellarys-viewer) is a
  Firestorm-based hobby viewer with the AMD flicker fix, permission-based posing
  of other avatars and built-in update checks, with more features as it develops.

Both are independent hobby projects with their own settings, cache and updates.
